What is it?
A fraction shows part of a whole. The numerator on top counts the parts you have, and the denominator below shows how many equal parts make the whole.
Key rules
- Add unlike fractions by first using a common denominator.
- To multiply, multiply the tops and multiply the bottoms.
- Simplify by dividing top and bottom by their highest common factor.
Worked examples
Example 1: Add 1/2 + 1/3
1. Common denominator is 6: 1/2 = 3/6 and 1/3 = 2/6
2. Add the numerators: 3 + 2 = 5, so 5/6
3. Check that 5/6 cannot be simplified further
Answer: 5/6
Example 2: Multiply 2/3 x 3/5
1. Multiply the tops: 2 x 3 = 6
2. Multiply the bottoms: 3 x 5 = 15, so 6/15
3. Divide top and bottom by 3: 6/15 = 2/5
Answer: 2/5
Common mistake
Adding the denominators, so 1/2 + 1/3 is wrongly written as 2/5. The denominator stays the same when you add; only the numerators combine.
